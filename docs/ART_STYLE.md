# Сага Севера — паспорт стиля арта

Утверждённый стиль: **скандинавская гравюра, красная версия** (эталон — картинка Сигрид-берсерка).

Статус: 6 героев и 4 врага главы 1 нарисованы и утверждены (16.10.2026). Новых персонажей рисовать по этому файлу, прикладывая эталон Сигрид.

## 1. Общий блок стиля (вставлять в КАЖДЫЙ промпт)

```
Стиль: скандинавская гравюра, как ожившая иллюстрация к древней саге.
- Плоские цвета без градиентов и мягких теней.
- Жирные чёрные контурные линии, как тушью; объём — только короткой резкой штриховкой.
- Строгая палитра из 4 цветов: чёрный (#1a1a1a), цвет старой кости (#efe3c8), ржаво-красный (#b5442c), холодный синий (#3f6a96). Других цветов нет. Кожа — цвет кости с лёгкой штриховкой.
- Лёгкая фактура старой бумаги.
- Скандинавский плетёный орнамент на одежде, оружии, пряжках и щитах.
- Чёткий узнаваемый силуэт: персонаж должен читаться в размере 150×150 пикселей.
- Без текста, подписей, рамок и водяных знаков.
- Ориентируйся на прикреплённую картинку Сигрид как на эталон: та же толщина линий, та же палитра, та же степень детализации.
```

## 2. Формат картинки

**Герои:**
```
Формат: персонаж в полный рост целиком в кадре, с небольшим отступом от краёв. Ракурс три четверти, смотрит ВПРАВО, боевая стойка. Прозрачный фон; если нельзя — ровный ярко-зелёный фон (#00ff00) без теней. Квадрат 1024×1024.
```

**Враги:**
```
Формат: персонаж в полный рост целиком в кадре, с небольшим отступом от краёв. Ракурс три четверти, смотрит ВЛЕВО, угрожающая стойка. Прозрачный фон; если нельзя — ровный ярко-зелёный фон (#00ff00) без теней. Квадрат 1024×1024.
Цветовое правило врагов: основа — чёрный, цвет кости и холодный синий. Ржаво-красный — только как ржавчина на металле и пятна крови, НЕ на одежде, плащах и обмотках (красная одежда — цвет героев). Враг должен с первого взгляда отличаться от героев по цвету.
```

## 4. Как генерировать

1. Один **обычный** чат ChatGPT на всех персонажей (не временный): так стиль держится одинаковым.
2. Первое сообщение: прикрепить эталонную картинку Сигрид и написать: «Это эталон стиля для всей игры. Все следующие персонажи — строго в этом стиле». Затем вставить общий блок стиля.
3. Дальше по одному сообщению на персонажа: формат (герой или враг) + описание. Эталон прикладывать каждый раз — это заметно повышает одинаковость.
4. Проверка каждой картинки:
   - только 4 цвета палитры (синее сияние магии допустимо);
   - линии той же толщины, что у Сигрид;
   - герой смотрит вправо, враг — влево;
   - персонаж целиком в кадре;
   - уменьшить до размера ногтя: силуэт узнаётся.
5. Если не так — попросить переделать конкретное: «линии толще, как у эталона», «убери жёлтый цвет», «разверни вправо».
6. Сохранять в iCloud: `Saga Severa/art/heroes/` и `Saga Severa/art/enemies/`, имена латиницей: `sigrid.png`, `thorvald.png`, `eyvind.png`, `skadi.png`, `angrboda.png`, `hrungnir.png`, `draugr.png`, `wolf.png`, `draugr_archer.png`, `draugr_king.png`.
