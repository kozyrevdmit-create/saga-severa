# Бэклог — идеи на потом

Здесь собраны идеи Дмитрия, которые **сейчас не делаем**. Делать их можно только после отдельного решения: когда Дмитрий возьмёт идею в работу, её переносят в задачу этапа, а утверждённые правила — в [SPEC_CHANGES.md](SPEC_CHANGES.md).

| Идея | Зачем | Заметки |
|---|---|---|
| **Паки животных на карте**, восстанавливаются по таймеру (например, раз в 2 часа) | Фарм опыта и серебра. Причина заходить в игру несколько раз в день | Делать вместе с рисованием карты |
| **Ярость босса**: если бой идёт дольше ~2 минут, босс бьёт всё сильнее | Затянувшийся бой с боссом заканчивается сам. Сейчас из него выходят кнопкой «Отступить» | Поменяет баланс этапа 10, нужна проверка симуляцией |
| **Развилки и события на карте главы**: торговец, сундук, опасный бой | Выбор на карте и разнообразие между этапами | — |
| **Поселение**: здания с бонусами, рост оффлайн-дохода | Своя прокачка и смысл экрана «Поселение» | Сейчас поселение показывает только оффлайн-доход |
